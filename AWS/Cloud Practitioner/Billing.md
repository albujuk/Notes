# AWS Billing & Cost Management

Services for forecasting, tracking, managing, and viewing AWS costs.

---

## AWS Organizations

Centralized management and governance of AWS accounts. Groups accounts, applies security policies, and consolidates billing under a single payment method.

**Use cases:** Consolidate multiple AWS accounts into one organization, implement organization-wide policies, and consolidate billing.

See also: [[Governance#AWS Organizations|Organizations in Governance]] for multi-account governance context.

---

## AWS Billing and Cost Management Dashboard

Centralizes cost management — shows current charges, usage, forecasts, and detailed breakdowns. Also manages payments, views invoices, sets budgets, and consolidates billing.

**Use cases:** Visualize and report monthly AWS spend; set up and manage payment methods.

---

## AWS Budgets

Set custom budgets and receive alerts when costs, usage, or Savings Plans / Reserved Instances utilization or coverage exceed defined thresholds.

**Use cases:** Alert when projected costs exceed thresholds; forecast future expenses based on current usage trends.

---

## AWS Cost Explorer

Visualize, analyze, and manage AWS costs and usage with interactive graphs, reports, and forecasts. Provides insights into spending patterns, trends, and Reserved Instance recommendations.

**Use cases:** Analyze historical spending trends to find cost-saving opportunities; forecast future AWS costs to budget effectively.

---

## AWS Pricing Calculator

Web-based planning tool for creating cost estimates before deployment. Input instance types, storage options, and data transfer volumes to get a detailed cost breakdown.

**Use cases:** Estimate potential costs before deployment; compare costs of different AWS services and configurations.
