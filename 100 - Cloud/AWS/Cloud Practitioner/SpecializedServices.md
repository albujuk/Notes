# Specialized AWS Services

---

## Development Services

| Service | Description |
|---------|-------------|
| **AWS CodeBuild** | Fully managed CI service; compiles source code, runs tests, produces deployment packages; scales automatically; pay per build time |
| **AWS CodePipeline** | Fully managed CI/CD; automates build, test, and deploy phases; no servers to provision |
| **AWS X-Ray** | Tracing, debugging, and performance analysis; visualize application behavior; identify bottlenecks |
| **AWS AppSync** | Fully managed GraphQL service; single API over multiple data sources; connects frontend to backend |
| **AWS Amplify** | Build, deploy, and manage full-stack apps on AWS; adds auth, APIs, storage, and hosting with minimal infra management |

---

## Business Application Services

| Service | Description |
|---------|-------------|
| **Amazon Connect** | AI-powered contact center; call routing, recording, and analytics; integrates with other AWS services |
| **Amazon SES** | Scalable email service for high-volume transactional and marketing email automation |

---

## End-User Computing Services

| Service | Description |
|---------|-------------|
| **Amazon AppStream 2.0** | Streams desktop/SaaS applications from the cloud to any device; no high-end local hardware needed |
| **Amazon WorkSpaces** | Fully managed cloud desktop; employees access work environment from any device |
| **Amazon WorkSpaces Secure Browser** | Managed remote enterprise browser; access private sites and SaaS apps without VPN or client software |

---

## IoT Services

| Service | Description |
|---------|-------------|
| **AWS IoT Core** | Connects physical devices to cloud applications; handles data ingestion, processing, and actions; mutual authentication + end-to-end encryption; multiple protocol support |

**Example IoT solutions:** smart security cameras, remote pet feeders, weather-adaptive irrigation systems.
