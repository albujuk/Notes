# AWS Billing & Cost Management

Services for forecasting, tracking, managing, and viewing AWS costs.

---

## AWS Organizations

Centralized management and governance of AWS accounts. Groups accounts, applies security policies, and consolidates billing under a single payment method.

**Use cases:** Consolidate multiple AWS accounts into one organization, implement organization-wide policies, and consolidate billing.

See also: [[Governance#AWS Organizations|Organizations in Governance]] for multi-account governance context.

---

## AWS Billing and Cost Management Dashboard

Centralized platform for managing and understanding AWS charges. View and download invoices, monitor discounts and credits, analyze spending trends across multiple accounts, set budgets, and consolidate billing.

**Use cases:** Visualize and report monthly AWS spend; set up and manage payment methods.

---

## AWS Budgets

Set custom budgets and receive alerts when costs, usage, or Savings Plans / Reserved Instances utilization or coverage exceed defined thresholds. Supports automated actions to prevent overspending.

**Use cases:** Alert when projected costs exceed thresholds; forecast future expenses based on current usage trends.

---

## AWS Cost Explorer

Visualize, analyze, and manage AWS costs and usage with customizable reports and cost forecasting. Provides insights into spending patterns, trends, and Reserved Instance recommendations.

**Use cases:** Analyze historical spending trends to find cost-saving opportunities; forecast future AWS costs to budget effectively.

---

## AWS Pricing Calculator

Free, web-based planning tool for creating detailed cost estimates before deployment. Input instance types, storage options, and data transfer volumes to get a cost breakdown by service.

**Use cases:** Estimate potential costs before deployment; compare costs of different AWS services and configurations.

---

## AWS Service Pricing Pages

Per-service pricing pages detail costs for storage, requests, data transfer, instance types, and additional features. Include AWS Free Tier details for new customers.

**Examples:** [Amazon S3 Pricing](https://aws.amazon.com/s3/pricing/?nc=sn&loc=4) · [Amazon EC2 On-Demand Pricing](https://aws.amazon.com/ec2/pricing/on-demand/)
